# payhub Component Docs Conventions

This folder explains how UI components should be designed, named, reused, and documented.

## Rules

- Keep component guidance aligned with `payhub/SKILL.md`.
- Prefer reusable SwiftUI components only when reuse is real or imminent.
- Document component purpose, inputs, states, and accessibility expectations.
- Keep component names clear and domain-specific.
- Avoid turning one-off screen layout into shared components too early.
- Update `COMPONENTS.md` when component conventions change.
- Propose updates to `payhub/SKILL.md` if component rules affect app structure.
